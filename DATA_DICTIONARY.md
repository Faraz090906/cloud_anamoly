# Data Dictionary

All data in this repo is **SYNTHETIC** (CloudTrail-style), generated by `src/data_generator.py` (seed 42).

## Event fields (model input)
| Field | Description |
|---|---|
| eventTime | UTC timestamp (parsed to datetime) |
| eventSource | AWS service, e.g. `s3.amazonaws.com` |
| eventName | API call, e.g. `GetObject` |
| userName | Caller identity (flattened from `userIdentity` for raw CloudTrail) |
| sourceIPAddress | Caller IP |
| awsRegion | AWS region |
| userAgent | Client string (ingested, not used as a feature in Month 1) |
| errorCode | Present when the call failed (e.g. `AccessDenied`) |
| eventID | Unique ID (used only for de-duplication and label joining) |

## Engineered features
hour, day_of_week, is_error, user_events_10min, user_failures_10min, ip_events_10min
(plus one-hot: eventName, eventSource, awsRegion, userName).

## Ground truth (evaluation only, separate file `synthetic_labels.csv`)
| Field | Description |
|---|---|
| eventID | Join key |
| is_anomaly | 1 if injected scenario |
| scenario | routine, burst, repeated_failures, unusual_region, privilege_activity, unfamiliar_event |
